# Changelog

All notable changes to scripts in this repository will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),  
and this repository follows [Semantic Versioning](https://semver.org/), applied per script.

Version numbers reflect the evolution of individual scripts:
- **PATCH** [v1.0.1] — for small bug fixes or corrections.
- **MINOR** [v1.1.0] — for backward-compatible enhancements or new features.
- **MAJOR** [v2.0.0] — for breaking or non-backward-compatible changes.
